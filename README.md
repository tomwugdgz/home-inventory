## 一、怎么跑（30 秒启动）

```bash
cd d:/Mirofish/home-inventory-demo
# 首次使用：复制配置模板并填入你的 AI Key
cp config.example.env .env      # Windows: copy config.example.env .env
# 编辑 .env，把 AI_KEY= 换成你的真实 Key
python server.py
```

> 🔒 **安全说明**：AI Key 只从环境变量或本地 `.env` 读取（`.env` 已加入 `.gitignore`，不会上传 GitHub）。公开仓库里只有 `config.example.env` 模板，不含真实 Key。

启动后终端会打印两个地址：
- **电脑**：`http://localhost:8891`
- **手机**：`http://192.168.3.167:8891`（手机连**同一个 WiFi**）

> 手机打不开？检查：① 手机和电脑在同一 WiFi（不是访客网/不能是流量）② Windows 防火墙放行 8891 端口（首次会弹窗，勾"专用网络"允许）。

## 二、这个 Demo 真实接入了 AI

- AI 端点：`http://127.0.0.1:31415/v1`（你提供的本地中转服务）
- 视觉模型：`sensenova-6.8-flash-lite`（实测连续 3 次稳定返回：雨伞 / 蓝 / 居家备用 / 置信度 0.99）
- **API Key 只写在 `server.py` 里，不暴露给手机浏览器** —— 手机请求先到电脑服务器，服务器再转发给 AI
- 拍照流程：手机拍图 → 压缩到 1024px → 传电脑 → 调 AI → 自动填「物品名 / 类别 / 颜色 / 用途 / 置信度」→ 存本地

## 五、核心商业结论

- **双引擎**：NFC 贴耗材复购（硬件粘性）+ AI 会员订阅（Token 配额）
- **Token 是计量单位不是定价依据**：单次成本仅 ¥0.0014，付费买的是「AI 提效、找得到」
- **NFC 贴能卖的前提**：贴纸只存 UID、数据云端绑定 → 同一批贴跨 iPhone/安卓通用
- **D6 裁决（已采纳）**：NFC 绑定用独立 `nfc_binding` 映射表，不塞进 Homebox 核心表，支持一物多贴、换绑历史
