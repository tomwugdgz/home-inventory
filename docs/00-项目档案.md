> 全栈智造专家团 · 建档 2026-11-19 · 更新 2026-11-19 22:55 · 流程 v2.5.1

## 六要素
- **项目名称与定位**：家物志 —— 拍照/NFC 秒记「东西放哪」+ AI 自动归类，家庭共享的物品收纳管理
- **平台选型**：App + 微信小程序双端（用户已选）；iPhone / 安卓混用
- **技术栈**：底座 Homebox（Go+Vue 自托管）+ companion（AI 识别）+ NFC UID 云端绑定 + 小程序；**当前 Demo 用 Python 标准库本地服务器 + 局域网访问 + 真实 AI 代理**
- **当前阶段**：Phase 1 立项完成 + 本地 Demo 交付（AI 已真实接入）
- **已完成产出**：
  1. GitHub 开源侦察（Homebox 生态）
  2. 可跑 Demo `index.html`（拍照真实 AI / NFC 绑定 / 会员 Token / NFC 商城 / 位置树 / 搜索 / AI 整理 / localStorage）
  3. 本地服务器 `server.py`（0.0.0.0:8891 托管页面 + `/api/vision` AI 代理，Key 藏服务端）
  4. 5 份方案文档（00~04）
- **下一步计划**：Tom 拍板商业模式决策 → Phase 2 质量保障 → MVP 开发排期

## 架构决策摘要
- 选 Homebox 而非从零自研：复用物品/位置树/标签/照片/二维码/多用户，省 60-70% 后端
- NFC 双轨：安卓 NDEF 读写；iOS 预编码 UID 贴 + 二维码兜底
- **D6 裁决（2026-11-19 收口）**：NFC 绑定用独立 `nfc_binding` 映射表，不塞进 Homebox 核心表——支持一物多贴、换绑历史、不动核心模型。需求侧（product-scout）无异议，方案 B 通过。
- AI 用视觉模型 `sensenova-6.8-flash-lite`（实测稳定）；API Key 只在服务端
- 商业模式：NFC 贴耗材 + AI 会员双引擎；Token 是计量单位不是定价依据
